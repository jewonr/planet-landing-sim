# PLANETFALL — 행성 착륙 시뮬레이터

행성과 우주선의 변수를 바꿔 가며 착륙에 도전하는 2D 시뮬레이션입니다.

**바로 해 보기:** https://jewonr.github.io/planet-landing-sim/

## 조절할 수 있는 것

| 행성 | 우주선 |
| --- | --- |
| 지구 · 달 · 외계행성 선택 | 형태: 구형 · 전투기형 · 유선형 · 도넛형 · 원뿔형 |
| 중력가속도 (1 ~ 30 m/s²) | 질량, 크기 |
| 공기저항 = 대기 밀도 (지구의 0 ~ 5배) | 초기 속도, 진입 각도 |
| | 착륙 장치: 낙하산 지름, 역추진 연료 |

우주선은 100 km 상공에서 출발합니다. 내려오는 동안 **열 피해**(표면 온도가 내열 한계 초과),
**하중 피해**(감속 G가 한계 초과), **충돌 피해**(착지 속도 초속 4 m 초과)를 받으며,
선체 내구도가 남은 채로 땅에 닿으면 착륙 성공입니다.

## 모형의 가정

- 둥근 행성 위의 2차원 운동, 중력은 거리 제곱에 반비례
- 대기 밀도는 고도 7.2 km마다 약 2.7배씩 감소 (모든 행성 동일)
- 외계행성의 반지름은 지구와 밀도가 같다고 보고 중력가속도에 비례
- 가열은 Sutton–Graves 정체점 가열식, 표면 온도는 복사 평형 온도
- 행성 자전, 바람, 자세 제어는 고려하지 않음
